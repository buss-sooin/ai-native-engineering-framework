# AI Native Engineering Framework

Status: Effective

## Purpose

AI와 사람이 소프트웨어 프로젝트를 설계·구현·검증할 때 사용하는 공통 원칙, 워크플로, 품질 기준과 재사용 가능한 방법론을 관리한다.

Effective 상태는 현재 내용이 Human Acceptance를 거쳐 Framework-level Governance로 적용됨을 의미한다.

Framework-level Canonical Governance는 [`governance/AI-ENGINEERING-GUIDELINES.md`](governance/AI-ENGINEERING-GUIDELINES.md)에서 관리한다.

이 저장소는 특정 기술의 구현 절차나 개별 Project의 Workflow 자체를 직접 정의하지 않는다. 그러한 세부사항은 적절한 Workflow, Project 또는 Task Scope에서 관리한다.
